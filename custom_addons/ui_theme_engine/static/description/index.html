Premium UI Theme

A complete backend re-skin for Odoo 18 — without touching your data.

Design tokens, a coherent component library, a redesigned app shell (sidebar, navbar, dashboard) and restyled views. Business logic is untouched: this module ships styling, tokens and additive OWL components only.

Classic stays one click away

Installing the theme activates the Premium skin for every internal user. Nothing is lost: the native Odoo interface is still there, and each user can switch back at any time from the user menu (Skin: Classic / Premium). The preference is stored per user, so it follows them across devices.

Uninstalling the module removes the skin entirely and returns the database to the stock Odoo interface.

Light & Dark

Premium ships its own token-driven Light and Dark themes, toggled instantly from the user menu. The layout, spacing and components are identical in both: only semantic color tokens are swapped, so contrast and readability hold up either way.

What's inside

  • UI Brand Tokens — design tokens as CSS custom properties (--pui-*) plus Odoo $o-* overrides.
  • UI Premium Shell — app sidebar, navbar search, dashboard, component library.
  • Premium UI Theme — skin switch, asset bundle wiring, login screen.
  • Restyled form, list, kanban, calendar, chatter and settings views.
  • Motion system honouring prefers-reduced-motion.
  • Premium login screen, controlled instance-wide by the pui.login_skin system parameter.
