======================================================================
2. CORE ARCHITECTURAL QUESTION
======================================================================

The architecture must answer:

"What happens when the platform cannot reach the Control Plane?"

And separately:

"What happens when the device is temporarily disconnected?"

And separately:

"What happens when the device is permanently offline?"

And separately:

"What happens when connectivity is intermittent?"

These are different operating conditions.

======================================================================
3. OFFLINE CAPABILITY LEVELS
======================================================================

Evaluate at minimum:

LEVEL 0
-------
No offline capability.

LEVEL 1
-------
Offline viewing / cached information.

LEVEL 2
-------
Offline data capture with later synchronization.

LEVEL 3
-------
Offline workflow execution using bounded local capabilities.

LEVEL 4
-------
Offline agent execution with constrained tools.

LEVEL 5
-------
Substantial autonomous edge execution.

These are candidate levels.

Claude MUST determine whether this taxonomy is appropriate.

======================================================================
4. DO NOT ASSUME FULL OFFLINE AUTONOMY
======================================================================

The default architecture must NOT assume that an agent should continue
to operate autonomously when disconnected.

For every capability determine:

- whether it can operate offline
- whether it should operate offline
- whether it must operate offline
- whether it must stop when offline.

permanently isolated.
