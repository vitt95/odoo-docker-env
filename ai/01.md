# Visione del Progetto

L'obiettivo del progetto è introdurre un nuovo paradigma di interazione con Odoo.

Oggi Odoo viene utilizzato attraverso menu, viste, filtri, pulsanti e form.

L'obiettivo è permettere agli utenti di interagire con l'ERP esprimendo semplicemente la propria intenzione, utilizzando il linguaggio naturale.

L'utente non dovrà più conoscere il software.

Dovrà conoscere solamente il proprio lavoro.

L'AI rappresenta un nuovo livello di interazione tra utente e sistema.

Non sostituisce Odoo.

Non sostituisce la logica di business.

Non sostituisce il motore ORM.

Interpreta esclusivamente l'intenzione dell'utente.

L'esecuzione rimane sempre completamente deterministica.

---

# Filosofia del Prodotto

Questo progetto **non è una chatbot**.

Non è un assistente conversazionale generico.

Non è un sistema che prende decisioni autonome.

È una piattaforma di **Interazione in Linguaggio Naturale** (Natural Language Interaction Layer - NLIL), indipendente dal canale utilizzato.

La chat rappresenta solamente il primo canale di comunicazione.

L'architettura dovrà essere progettata affinché in futuro sia possibile utilizzare lo stesso motore tramite:

* Chat
* Voce
* Applicazione Mobile
* Microsoft Teams
* Slack
* API
* Email
* Interfacce multimodali

Il motore di comprensione dovrà essere completamente indipendente dal canale di comunicazione.

---

# Obiettivo della Prima Release

La prima release è volutamente limitata.

L'obiettivo è permettere all'utente di interrogare Odoo utilizzando il linguaggio naturale.

L'utente scrive una richiesta.

Il sistema interpreta la richiesta.

Il sistema produce un DSL (Domain Specific Language).

Il backend trasforma il DSL in operazioni ORM deterministiche.

Infine viene aperta automaticamente una vista Odoo contenente il risultato.

Non devono essere progettate funzionalità non necessarie alla prima milestone.

# Funzionalità Attese

Il sistema dovrà permettere richieste come:

"Mostrami gli ultimi cinque ordini."

"Fammi vedere solo quelli confermati."

"Visualizza cliente, commerciale e importo."

"Ordina per data."

"Mostra solamente quelli di questo mese."

"Apri il primo."

"Visualizza il risultato in Kanban."

"Mostrami le auto con circa centomila chilometri."

"Mostra solo le fatture scadute."

"Raggruppa per venditore."

"Fammi vedere solamente Nome, Email e Telefono."

L'utente dovrà inoltre poter modificare progressivamente il risultato tramite conversazione.

Ad esempio:

Mostrami tutti i clienti.

↓

Solo quelli attivi.

↓

Ordina per città.

↓

Mostrami anche il telefono.

↓

Apri il primo.

Il sistema dovrà comprendere il contesto della conversazione.

L'utente dovrà poter richiedere direttamente dalla conversazione:

* ordinamenti
* raggruppamenti
* filtri
* numero di record
* vista Lista
* vista Kanban

Il sistema dovrà costruire dinamicamente la vista più adatta senza richiedere configurazioni manuali.

# Filosofia di Esecuzione

L'AI non esegue operazioni.

L'AI interpreta esclusivamente l'intenzione dell'utente.

L'unico output prodotto dall'AI è un DSL strutturato.

Il DSL rappresenta il contratto tra AI e backend.

Tutte le operazioni successive devono essere completamente deterministiche.

La definizione del DSL non fa parte di questo documento.
