# UI.md

# Visione

L'interfaccia deve trasmettere:

* Premium
* Pulizia
* Fiducia
* Velocità
* Precisione
* Modernità

L'utente non deve percepire Odoo.

Deve percepire un moderno prodotto SaaS.

---

# Ispirazione

Prendere ispirazione dai principi di prodotti come:

* Linear
* Stripe Dashboard
* Notion
* Vercel
* Apple
* Raycast

Non copiarne l'aspetto.

Copiarne la qualità progettuale.

---

# Principi

Ridurre il rumore.

Massimizzare la leggibilità.

Usare gerarchie visive chiare.

Ogni elemento deve avere uno scopo.

---

# Layout

Molto spazio.

Allineamenti rigorosi.

Card leggere.

Bordi discreti.

Ombre morbide.

---

# Motion

Animazioni brevi.

Transizioni fluide.

Mai rallentare il lavoro dell'utente.

Le animazioni devono essere quasi impercettibili.

---

# Componenti

Tutti i componenti devono appartenere allo stesso Design System.

Button

Input

Select

Dropdown

Dialog

Toast

Badge

Table

Card

Sidebar

Navbar

Kanban

Form

List

Calendar

Chatter

---

# Responsive

Desktop prioritario.

Tablet completamente supportato.

Mobile compatibile dove possibile.

---

# Accessibilità

Contrasto corretto.

Focus visibile.

Navigazione da tastiera.

Animazioni rispettose delle preferenze utente.

---

# Regola fondamentale

Mai progettare una schermata isolata.

Ogni nuova schermata deve utilizzare esclusivamente componenti appartenenti al Design System.

Se un componente non esiste, va progettato prima il componente e solo successivamente la schermata.

---

# Modalità di lavoro

Per ogni schermata:

1. Analisi tecnica
2. Analisi UX
3. Proposta di redesign
4. Individuazione componenti
5. Implementazione
6. Review finale

Non iniziare mai direttamente dal CSS.

Prima comprendere il comportamento del componente.

Poi progettare.

Infine implementare.
