======================================================================

Runtime and the actual model execution infrastructure.

- Qwen3.5 9B
- one model

- one machine
- modest hardware
- local inference
- small engineering team

- multiple models

- specialized models
- embeddings
- rerankers
- multimodal models
- tenant-specific models
- model-specific policies
- model canary deployments
- model evaluation

- model lifecycle management

MODEL IDENTITY

from:

MODEL SERVING INFRASTRUCTURE.

3. CORE ARCHITECTURAL QUESTION
======================================================================

Determine the correct boundary between:

Agent Runtime

and:

Model / Inference Layer.

The Agent Runtime should express:

"I need model X to perform operation Y."

The inference layer should determine:

- where model X is running
- which worker handles it
- how the request is scheduled
- how generation occurs
- how resources are allocated
- how the result is returned

But determine whether this abstraction is actually appropriate.

Research and decide.
