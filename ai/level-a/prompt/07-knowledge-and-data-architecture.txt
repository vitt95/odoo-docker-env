3. CORE PRINCIPLE
======================================================================

Explicitly investigate the distinction between:

DATA

KNOWLEDGE

MEMORY

CONTEXT

RETRIEVAL

The platform must NOT collapse all five concepts into one database.

Determine the correct boundaries.

At minimum investigate:

DATA
----
Authoritative enterprise information.

KNOWLEDGE
---------
Information prepared for retrieval and reasoning.

MEMORY
------
Information representing agent/user interaction history or learned
operational context.

CONTEXT
-------
Information assembled for a specific model invocation.

RETRIEVAL
---------
The process of finding relevant information.

These concepts may use shared infrastructure, but they are not identical.

C.
