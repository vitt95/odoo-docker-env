6. WHEN SHOULD AN AGENT EXIST?
======================================================================

This is a critical architectural question.

A new agent should not exist merely because a prompt can be separated.

Evaluate whether a capability should instead be:

- a Tool
- a Workflow
- a deterministic Service
- a Model call
- a Library
- an Agent

Define objective criteria.

Examples:

Use a Tool when:
- deterministic external capability
- explicit API
- limited reasoning required

Use a Workflow when:
- deterministic sequence
- explicit state transitions
- predictable orchestration

Use an Agent when:
- autonomous reasoning
- adaptive planning
- independent context
- independent responsibility
- meaningful specialization

These are hypotheses.

Research and validate them.

25. TIMEOUTS
======================================================================

Nested agents can create timeout amplification.

A calls B = 60s

B calls C = 60s
