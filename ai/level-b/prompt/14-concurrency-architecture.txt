3. CENTRAL PRINCIPLE
======================================================================

CONCURRENCY IS NOT ONE NUMBER.

A system can simultaneously have:

10 agent runs

2 model generations

20 network calls

5 tool executions

8 database queries

and:

1 GPU.

Therefore:

DO NOT CREATE ONE GLOBAL "MAX CONCURRENCY" SETTING AND CALL THE PROBLEM
SOLVED.

Model concurrency by RESOURCE AND EXECUTION DOMAIN.

4. LEVEL B CONSTRAINT
======================================================================

This is:

LEVEL B — PREPARED DAY 1.

- distributed global scheduler
