3. CENTRAL PRINCIPLE
======================================================================

NETWORK LOCATION ≠ TRUST.

A component being:

- inside a VPC
- inside a VNet
- inside a Kubernetes cluster
- inside a private subnet
- on the same node

must NOT automatically imply:

TRUST.

Networking must establish controlled communication paths.

Application authorization remains authoritative.

======================================================================
4. LEVEL B CONSTRAINT
======================================================================

This is:

LEVEL B — PREPARED DAY 1.

Day 1 does NOT require:

- complex multi-region networking
- global traffic management
- full enterprise SASE
- dedicated network per tenant
- service mesh everywhere
- private connectivity for every external service
- advanced network segmentation across dozens of zones.

But Day 1 MUST establish:

- explicit traffic boundaries
- controlled ingress
- controlled egress
- service-to-service authorization
- encrypted communication
- network observability
- basic network policy
- clear trust zones.
